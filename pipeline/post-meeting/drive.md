identificador que copia el asistente. **Nunca se escribe a mano**: se copia de

## Cómo se comprueba

**Para las personas:** si alguna vez una carpeta no aparece o un documento ha ido
a parar a otro sitio, se comprueba contra el Drive en el momento — así no se
decide «de memoria». La comprobación la hace el asistente; aquí queda el comando
para que no se pierda.

**Para el asistente (LLM):** la dirección del servidor está en la configuración
del asistente (no viaja en esta hoja). El comando se lanza **desde la raíz del
repositorio** (donde está `referencia/verificar-drive.py`):

```bash
# en el VPS (la credencial vive allí, NO en este repositorio)
scp referencia/verificar-drive.py root@<servidor>:/tmp/
ssh root@<servidor> '/opt/whisper-transcribe/venv/bin/python3 /tmp/verificar-drive.py'
```

El script solo lee: para cada bandeja imprime su nombre, su dirección y la cadena
de carpetas a la que pertenece. Si algo no cuadra con esta hoja, **manda lo que
diga el Drive** y se corrige la hoja.

---

**Nota:** las direcciones no son secretos, pero son la llave de acceso a los
documentos. Por eso esta hoja vive en el repositorio privado y no se publica
fuera de la organización.
